Questions fréquentes

🚀 Comment fonctionne le bump ?

Les bumps permettent de mettre temporairement ton serveur en avant dans les résultats.

❤️ Comment voter pour un serveur ?

Ouvre la page d'un serveur puis utilise le bouton de vote pour soutenir la communauté.

🌐 Comment ajouter mon serveur ?

Connecte-toi avec Discord puis utilise la page Ajouter un serveur depuis ton dashboard.

🚨 Comment signaler un serveur ?

Depuis la page du serveur, utilise le bouton Signaler afin d'envoyer un signalement à notre équipe.
